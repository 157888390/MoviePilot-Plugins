# 硬链接联动清理（HardLinkCleaner）

单向监控**源目录**，当源目录中的文件/文件夹被删除（或移出）时，自动清理**硬链接目录**中对应的硬链接及其刮削产物，并支持级联清理空目录。

> 与 `strmscraper`（监控 .strm 并刮削）是**两个不同的插件**，职责互补：本插件只负责“删源 → 清链”。

## 核心机制

### 1. 路径映射（核心挑战解答）

MoviePilot 的硬链接目录默认是源目录的**结构镜像**（相对路径一致），因此映射关系由目录结构直接推导，无需持久化字典：

```
link_path = hardlink_dir / source_path.relative_to(source_root)
```

- **O(1)** 查找、**零状态**、**自我修复**（文件移动/重命名后不会像 `dict` 那样过期失效）。
- 仅当硬链接目录与源目录结构**非镜像**时，才需要额外持久化索引（本插件默认不采用）。

### 2. 单向监控

- 仅用 watchdog 监控**源目录**（`recursive=True`），**绝不监控硬链接目录**。
- 监听 `on_deleted`：文件/文件夹被删除。
- 监听 `on_moved`：文件被移出源目录（如移到回收站、其他盘）→ 视为删除；源内重命名则跳过。

### 3. 联动删除

- **文件删除**：删除硬链接文件 + 其同 stem 刮削产物（`.nfo` / `.jpg` / `-thumb.jpg` / `-fanart.jpg` 等）。
  - 不删除剧集级/剧级文件（`tvshow.nfo`、`poster.jpg`、`Season 1/season.nfo` 等，stem 不同）——它们属于整部剧，仅在整目录删除时一并移除。
- **文件夹删除**：`shutil.rmtree` 删除整个硬链接目录及其全部内容（含其中的硬链接与刮削产物）。

### 4. 空目录级联清理

删除后从父目录向上级联 `rmdir`，直到硬链接根目录为止（不会删掉根目录本身）。可由「级联清理空目录」开关关闭。

### 5. 去抖与目录吸收

- 删除事件进入队列，延迟 `删除延迟(秒)`（默认 2s）后由后台线程统一执行，避免删除风暴中反复 IO。
- 目录删除事件会**吸收**其下已排队的子文件删除（整目录一次性处理）。

### 6. 孤儿清理扫描

「启动后孤儿扫描一次」或调用 API `GET /hardlink_cleanup`：扫描硬链接目录中**源已不存在**的文件并清理，再级联空目录。用于修复插件未运行期间产生的孤儿。

## 配置项

| 配置 | 说明 |
|------|------|
| 启用插件 | 开启单向监控 |
| 级联清理空目录 | 删除后向上级联删空目录 |
| 启动后孤儿扫描一次 | 启动 3 秒后跑一次孤儿清理 |
| 源目录 | 仅监控这些目录，每行一个（如 `/media/downloads/tv`） |
| 硬链接目录 | 不监控，仅清理（如 `/media/library`） |
| 监控模式 | 兼容模式（轮询，网络盘）/ 性能模式（inotify） |
| 删除延迟(秒) | 删除去抖窗口，默认 2 |

## 安全护栏

- 所有删除操作前校验目标路径**确实位于硬链接目录内**，拒绝删除任何越界路径。
- 仅处理源目录事件，绝不反向改动源目录或硬链接目录外的任何文件。

## 依赖

无额外依赖。`watchdog` 为主程序自带。

## 删除链路示意

```
源目录 /media/downloads/tv/Show S01E01.mkv 被删除
  → watchdog on_deleted
  → map: /media/library/电视剧/Show/Season 1/Show S01E01.mkv
  → 删除：Show S01E01.mkv + Show S01E01.nfo + Show S01E01-thumb.jpg ...
  → 若 Season 1 变空 → 删 Season 1 → 若 Show 变空 → 删 Show（级联）
```
