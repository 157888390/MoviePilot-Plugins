# NFO 补全插件（NfoCompleter）

监控指定目录下的 `.nfo` 文件，解析其内容，检测缺失或不完整的字段，并调用宿主 TMDB
模块补齐，最后原子写回。

## 功能

- **目录监控**：watchdog 实时监控（默认轮询模式，兼容 Docker / 远程挂载目录）+ 启动时
  全量扫描 + 定时扫描 + 手动 `/nfo_scan` 命令。
- **完整性校验**：识别 `movie` / `tvshow` / `episodedetails` 三类 NFO，逐字段判断是否
  缺失、为空或为占位值（`未知` / `Unknown` / `0` 等）。
- **TMDB 补全**：优先用 NFO 里已有的 `uniqueid(tmdb)` 精确取详情；否则用标题 + 年份
  搜索匹配。可补齐标题、原名、年份、首映日期、时长、简介、标语、评分、类型、导演、
  编剧、制片厂、国家、演员与 `uniqueid`。
- **写回安全**：只补缺失字段、不覆盖已有内容；写前备份（同目录 `.bak`）；临时文件 +
  `os.replace` 原子替换，避免写坏被播放器扫描到。

## 配置项

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| 启用插件 | 总开关 | 关 |
| 监控目录 | 每行一个目录，递归扫描其中所有 `.nfo` | 空 |
| 监控模式 | 兼容（轮询，适合远程挂载）/ 性能（inotify，仅本地盘） | 兼容 |
| 定时扫描 cron 表达式 | 定时全量扫描 | `0 3 * * *` |
| 写回前备份 | 补全前复制原文件为 `.bak` | 开 |
| 仅检测不写回 | dry-run，只记录缺失字段不落盘 | 关 |
| 完成后通知 | 暂未接入汇总通知 | 关 |

## 使用方式

1. 安装并启用插件，配置监控目录。
2. 插件会自动扫描存量 NFO 并监听新增/移入的 NFO。
3. 需要立即重扫时，发送远程命令 `/nfo_scan`。

## 注意

- 补全依赖宿主 TMDB 模块（需已启用并在运行）；TMDB 未运行时插件只能检测、无法补全。
- 剧集（`episodedetails`）补全依赖 NFO 里的 `uniqueid(tmdb)`（通常为剧集 id）或
  `showtitle` 来定位剧集，两者都缺失时无法补全该集。
- 定时扫描服务在 `DEV=true` 的开发实例上不会注册（宿主行为），正式实例才生效。
